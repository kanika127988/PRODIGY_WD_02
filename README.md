# 🚀 Prodigy InfoTech Web Development Internship - Task 02

## 📌 Project Overview
This repository contains **Task 02** of the Web Development Internship at **Prodigy InfoTech**. The objective of this task was to develop a fully functional, interactive **Stopwatch Web Application** featuring precise time tracking, start/pause controls, lap split logging, and a sleek dark-tech neon aesthetic.

---

## ✨ Key Features & Functionality
* **Real-Time Tracking:** Accurate millisecond, second, and minute time calculation using JavaScript timing functions.
* **Dynamic Controls:** Start, Pause, and Reset functionality with responsive button state transitions and visual indicators.
* **Lap Split Recorder:** Allows users to log multiple split/lap timestamps while the main stopwatch continues running in the background.
* **Modern UI/UX:** Styled using a sleek dark-mode glassmorphism card layout with glowing neon cyan accents and clean typography.

---

## 🛠️ Technologies Used
* **HTML5:** For structured markup of the stopwatch container, display, and control buttons.
* **CSS3:** For styling, flexbox alignment, backdrop filters, and custom scrollbars.
* **JavaScript (ES6+):** For state management, `setInterval` timer logic, DOM manipulation, and event handling.
* **FontAwesome:** For intuitive UI icons.
* **Google Fonts:** For modern typography (`Plus Jakarta Sans`).
